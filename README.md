ASSIGNMENT THREE QUESTIONS
1. What is the purpose of the try and catch blocks?
The try block contains code that may cause an exception. The catch block handles the exception when an error occurs.
2. Explain the difference between throw and throws.
throw is used to throw an exception, while throws declares that a method may throw an exception.
3. What is the purpose of the finally block?
The finally block executes after the try and catch blocks, whether an exception occurs or not.
4. Why is a custom exception useful in this application?
A custom exception helps handle specific registration errors, such as an invalid age, an invalid exam mark, or an invalid number of subjects.
